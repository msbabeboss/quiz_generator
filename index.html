What you get

Everything you need to run great quizzes

From quiz creation to live leaderboards, every feature is built in and ready to use out of the box.

⚡

Real-Time Leaderboard

Scores update live via Pusher WebSockets the moment a student submits. No page refresh needed — admins see everything instantly.

⏱️

Countdown Timer

Each quiz runs on a configurable timer. When time runs out the quiz auto-submits, filling unanswered questions with null scores.

🎯

Instant Auto-Grading

MySQL triggers grade every answer the moment it's inserted. Stored procedures compute final scores automatically on submission.

🔒

Secure by Default

bcrypt password hashing, CSRF tokens on every form, PDO prepared statements, and XSS-safe output throughout the entire codebase.

📋

MCQ & True/False

Create multiple-choice questions with 4 options (A–D) or True/False questions. Randomize question order per quiz.

📊

CSV Export

Download full results for any quiz as a CSV file — username, score, percentage, submission time, and status in one click.

🌙

Dark Mode

One-click dark mode toggle with localStorage persistence. Preference is remembered across sessions automatically.

👥

Role-Based Access

Admins create and manage quizzes; students take them. Every endpoint enforces role checks before any business logic runs.

🔔

Live Notifications

The admin dashboard plays a notification sound and prepends a new row to the live feed every time a student submits a quiz.

Simple process

Up and running in minutes

Four steps from setup to your first live quiz session.

1

Set Up

Import database.sql, fill in .env with your DB and Pusher credentials, run composer install.

2

Create a Quiz

Log in as teacher, add a quiz with a time limit, then add MCQ or True/False questions with point values.

3

Students Join

Students register, log in, and take the quiz or play flashcard mode from their dashboard.

4

Watch Live

The admin dashboard updates in real time — live submissions feed, leaderboard, and participant count via Pusher.
